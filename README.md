El proyecto Webgenerator es una herramienta de código abierto diseñada para generar conjuntos de datos sintéticos de interfaces y contenido web. Permite crear archivos HTML, capturas de pantalla correspondientes y archivos JSON con elementos HTML etiquetados, facilitando el entrenamiento de modelos supervisados y no supervisados. Además, ofrece la posibilidad de ajustar probabilidades y opciones de generación según las necesidades del usuario. 
GITHUB.COM

Este generador es especialmente útil para investigadores y desarrolladores que requieren grandes volúmenes de datos de interfaces web para entrenar y evaluar modelos de aprendizaje automático en tareas como el reconocimiento de elementos de la interfaz o la generación automática de contenido web.
